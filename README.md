# astrbot_plugin_draw_and_guess

AstrBot 插件 · **你画我猜**（Draw & Guess）— 复刻原版**竞猜模式**：群内开房、LLM 出题、私聊发题给作画者、群内提交画作、激活竞猜、生成图片排行榜。

## 流程

1. 玩家 A 在群里 `/draw_create` 开房（自动加入）。
2. 大厅阶段：
   - `/draw_join` 加入；
   - `/draw_leave` 退出；
   - `/draw_list` 查看成员；
   - `/draw_disband` 房主解散。
3. 房主 `/draw_start <领域>` 开始游戏（默认至少 2 人）。
4. 系统随机生成作画顺序，**每人各作画一次**。
5. 每轮：
   - LLM 根据领域生成一个 2-6 字的题目；
   - 题目通过**私聊**发给当前作画者 B（请确保 B 已与机器人为好友）；
   - 群里宣布作画者、领域、**答案字数**；
   - 机器人发一张 1080×1920 手机比例**白板图**，作画者长按 → 编辑 → 涂鸦 即可使用 QQ 自带画笔；
   - B 在群里发送 `/draw_submit` 并随消息附作画好的图片；
   - 进入竞猜阶段，机器人激活监听群消息；
   - 第一个**完全匹配**答案的玩家：猜对者 +2 分，作画者 +1 分；
   - 超时（默认 180s）则公布答案、不得分。
6. 全部回合结束后，机器人渲染**积分排行榜图片**（含每个玩家的头像、昵称、积分、顺位）并发送到群里。

## 指令

| 指令 | 别名 | 谁可用 | 说明 |
| --- | --- | --- | --- |
| `/draw_create` | 创建画猜 | 任何人 | 在当前群开房，自己自动加入 |
| `/draw_join` | 加入画猜 | 任何人 | 加入当前群房间（大厅阶段） |
| `/draw_leave` | 退出画猜 | 在房间内者 | 退出房间；房主退出则解散 |
| `/draw_list` | 画猜成员 / 画猜列表 | 任何人 | 查看状态 / 玩家 / 进度 |
| `/draw_disband` | 解散画猜 | 房主 | 解散房间 |
| `/draw_start <领域>` | 开始画猜 | 房主 | 输入领域开始游戏 |
| `/draw_submit` | 提交画作 | 当前作画者 | 同一条消息附图片 |
| `/draw_skip` | 跳过画猜 | 作画者 / 房主 | 跳过本轮，无人得分 |
| `/draw_status` | 画猜状态 | 任何人 | 查看当前进度 |
| `/draw_help` | 画猜帮助 / 画猜说明 | 任何人 | 显示游戏玩法和全部指令 |

> 实际前缀（`/` 或 `#` 或空）取决于 AstrBot 的全局配置。
>
> 下划线和空格两种写法等价：`/draw_join` ≡ `/draw join`、`/draw_start 动物` ≡ `/draw start 动物`。
> 注意写成 `/drawjoin`（无分隔）或拼错命令时不会匹配任何指令，消息会被当作普通聊天交给 LLM。

## 配置

在 AstrBot WebUI → 插件管理 → `astrbot_plugin_draw_and_guess`：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `llm_provider_id` | 空 | 出题用的 LLM Provider id；留空使用全局当前 Provider |
| `min_players` | 2 | 开始游戏所需最少玩家数 |
| `max_players` | 8 | 房间最大玩家数 |
| `draw_timeout` | 300s | 作画阶段超时（超时跳过该轮） |
| `guess_timeout` | 180s | 竞猜阶段超时（超时公布答案） |
| `score_correct` | 2 | 猜对得分 |
| `score_drawer` | 1 | 作画者每轮被猜中后得分 |
| `answer_min_len` / `answer_max_len` | 2 / 6 | LLM 出题字数约束 |

## 备注

- 私聊发题依赖平台支持（如 NapCat/aiocqhttp）。如果机器人无法私聊作画者，本轮会自动跳过。
- 头像取自 `q1.qlogo.cn`（QQ 平台），其他平台头像可能无法获取，排行榜会用占位图。
- 排行榜渲染优先使用插件目录或同宿主其它插件的 CJK 字体；找不到时回退到 PIL 默认字体（中文会变方框）。可以把任意 CJK ttf/otf 放到本插件目录下并命名为 `font.ttf` / `font.otf` 来覆盖。
- 答案匹配规则：去掉空白与常见标点（`-_,。.!?:;'"()[]<>《》/\` 等），不区分大小写。其他文本必须**完全一致**。
